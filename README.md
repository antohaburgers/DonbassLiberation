## Полигон v0.1

Первый играбельный прототип браузерного FPS. Это пока исследование местности, а не боевой режим.

- Случайная квадратная карта 1000 × 1000 м, 8 дорожных маршрутов, леса, 6 точек интереса и застройка.
- Стриминг участков рельефа 125 × 125 м, упрощённые 3D-модели и туман для мобильной производительности.
- Вид от первого лица, движение, бег, прыжок, столкновения, мини-карта, цель разведать все 6 объектов.
- Сенсорный стик/свайп, клавиатура/мышь, Xbox-совместимые Bluetooth-контроллеры через Gamepad API.
- Бои, оружие и противники будут в следующих версиях.

### Как запустить

Откройте опубликованный GitHub Pages-сайт по адресу https://antohaburgers.github.io/DonbassLiberation/ после включения Pages.

В репозитории **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**. Для WebGL требуется современный браузер и доступ в сеть: Three.js загружается с jsDelivr.

### Управление

- ПК: WASD, мышь (нажать на поле игры для захвата курсора), Shift — бег, Space — прыжок, Esc — пауза.
- Смартфон в горизонтальной ориентации: левый виртуальный стик — движение, свайп по свободной части экрана — обзор, кнопки БЕГ и ПРЫЖОК.
- Контроллер: левый/правый стики, A — прыжок, нажатие левого стика — бег.

### Исходники

- index.html — интерфейс
- style.css — оформление и мобильные элементы
- world-data.js — независимый генератор 2D-схемы квадратной карты
- world-render.js — 3D-рендер, чанки и столкновения
- input.js — клавиатура, касания и геймпад
- game.js — состояние игры и цикл кадров

**Основа дизайна** — идеи из проекта DerevnyaRally, но код 3D-карты написан отдельно для квадратного мира вместо бесконечной дорожной ленты.

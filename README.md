## Полигон v0.1

Первый играбельный прототип браузерного FPS. Это пока исследование местности, а не боевой режим.

- Случайная квадратная карта 1000 × 1000 м, 8 дорожных маршрутов, леса, 6 точек интереса и застройка.
- Стриминг участков рельефа 125 × 125 м, упрощённые 3D-модели и туман для мобильной производительности.
- Вид от первого лица, движение, бег, прыжок, столкновения, мини-карта, цель разведать все 6 объектов.
- Сенсорный стик/свайп, клавиатура/мышь, Xbox-совместимые Bluetooth-контроллеры через Gamepad API.
- Бои, оружие и противники будут в следующих версиях.

### Как запустить

Откройте опубликованный GitHub Pages-сайт по адресу https://antohaburgers.github.io/DonbassLiberation/ после включения Pages.

В репозитории **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**. Для WebGL требуется современный браузер и доступ в сеть: Three.js загружается с jsDelivr.

### Управление

- ПК: WASD, мышь (нажать на поле игры для захвата курсора), Shift — бег, Space — прыжок, Esc — пауза.
- Смартфон в горизонтальной ориентации: левый виртуальный стик — движение, свайп по свободной части экрана — обзор, кнопки БЕГ и ПРЫЖОК.
- Контроллер: левый/правый стики, A — прыжок, нажатие левого стика — бег.

### Исходники

- index.html — интерфейс
- style.css — оформление и мобильные элементы
- world-data.js — независимый генератор 2D-схемы квадратной карты
- world-render.js — 3D-рендер, чанки и столкновения
- input.js — клавиатура, касания и геймпад
- game.js — состояние игры и цикл кадров

**Основа дизайна** — идеи из проекта DerevnyaRally, но код 3D-карты написан отдельно для квадратного мира вместо бесконечной дорожной ленты.

## Version 0.5

Prototype now includes first-person rifle, camera-attached weapon animation, 76 simple NPCs with blue armbands, sound effects, health, ammo, reload, and control point gameplay. Controls: hold left mouse button / FIRE touch button / gamepad RT. Reload with R / touch RELOAD / gamepad X.


## PWA v0.7 — установка на телефон

Сайт: https://antohaburgers.github.io/DonbassLiberation/

Добавлен манифест, 192/512 px иконки и отдельная iOS-иконка, запуск standalone в горизонтальной ориентации, защита от браузерного масштабирования, случайного выделения текста, контекстного меню и прокрутки игры. Игровые PointerEvent не блокируются.

**Установить на iPhone:** открыть сайт в Safari → нажать «Поделиться» → «На экран Домой» → «Добавить». Запускать с появившегося значка. На Android/ПК использовать меню браузера «Установить приложение», когда функция доступна.

**Офлайн:** при первом запуске нужен интернет. Service worker сохраняет HTML, JS, стили, иконки и внешнюю библиотеку Three.js из CDN. Для сохранения Three.js в офлайн-кеше она должна хотя бы раз успешно загрузиться через интернет. Через меню можно запросить обновление игры. Первое открытие новой версии может потребовать повторного подключения к сети.

**Браузер:** отключены двойной тап для зума, pinch-zoom/жесты браузера, перетаскивание и прокрутка игрового поля. Системные функции масштабирования доступности iOS не управляются страницей. Меню можно прокручивать, чтобы настройки не обрезались на маленьком горизонтальном экране.

Исходная «Бесконечная Нива 3D» не изменялась.
